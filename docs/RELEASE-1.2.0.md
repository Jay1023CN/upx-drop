# UPX Drop 1.2.0

本次更新整合了新界面和批量队列功能。下载 **UpxDrop.exe** 即可使用，适用于 Windows 10 / 11 x64 和 .NET Framework 4.8。

## 更新内容

- 更新主界面、处理方式与压缩强度切换、文件状态、体积对比和操作反馈。
- 增加文件夹选择与后台递归扫描，自动去重，扫描可取消。
- 增加按文件名、路径和状态搜索筛选，以及失败、已取消文件的一键重试。
- 支持多选移出队列、处理中追加文件、进度统计和文件定位。
- 增加 CSV 结果导出，保留路径、状态、原始字节数和处理日志。
- 修正文件夹按钮裁切，明确区分应用版本与 UPX 引擎版本。

继续内嵌未修改的官方 UPX 5.2.1。压缩使用临时副本，校验通过后原子替换；支持可选备份，签名文件自动跳过。

## 下载文件

- **UpxDrop.exe**：直接运行的单文件程序。
- **UpxDrop.exe.sha256**：EXE 的 SHA-256 校验文件。
- **UpxDrop-1.2.0-source.zip**：应用完整源码、构建脚本和对应 UPX 源码归档。

## 验证

发布流水线运行队列与 WPF 交互测试、单文件离线启动、更新替换与回滚、真实 UPX 压缩和解压测试；真实原生测试程序在压缩后仍能运行。压缩率和兼容性取决于具体程序。
