# UPX Drop 1.2.2

UPX Drop 是一个 Windows EXE / DLL 批量压缩与解压工具，把 UPX 命令行做成了可直接操作的图形界面。拖入文件、选择压缩强度，就能批量处理，适合开发者在发布软件前给程序瘦身。

单 EXE 免安装，内置官方 UPX 5.2.1。文件处理全在本地完成，不上传文件。

## 主要功能

- **批量压缩与解压**：添加文件或拖入整个文件夹，自动扫描子目录、去除重复项；也能解压 UPX 压缩过的文件。
- **三档压缩强度**：快速、均衡、极致，按处理速度和体积需求选择，默认使用均衡。
- **队列管理**：支持自动或手动开始、处理中追加文件、停止任务，以及重试失败或取消的文件。一次最多加入 5000 个文件。
- **搜索与状态筛选**：按文件名、路径或处理状态查找，支持多选移出队列、清理已完成记录。
- **结果统计与导出**：查看每个文件处理前后的大小、变化比例和详细日志，统计整个队列节省的空间；处理记录可导出为 Excel 能打开的 CSV。
- **原文件保护**：先处理临时副本，压缩校验通过后再替换。失败或取消时保留原文件；自动跳过带数字签名、压缩后没有变小的文件，也可开启原文件备份。
- **高级压缩设置**：调整图标、附加数据、导出区段和重定位数据的处理方式，或尝试全部压缩方法。
- **自动更新**：检查 GitHub 上的新版本，下载并校验后，在退出时完成更新。

## 本次更新

修正下拉框误用 Windows 默认灰色按钮背景的问题。

- 状态筛选、附加数据和图标处理下拉框统一为白底、浅色边框。
- 悬停使用浅色反馈，展开和键盘聚焦使用淡蓝底与蓝色边框。
- 用蓝色焦点边框替代系统黑色虚线框，保留键盘操作提示。

## 下载与使用

1. 下载下方的 [**UpxDrop.exe**](https://github.com/Jay1023CN/upx-drop/releases/download/v1.2.2/UpxDrop.exe)，直接运行。
2. 选择压缩或解压，按需开启“保留原文件备份”。
3. 拖入 EXE、DLL 或文件夹。默认自动开始，也可以关闭自动开始后手动处理。

适用于 **Windows 10 / 11 x64**，需要 **.NET Framework 4.8**。无需另行下载 UPX，文件处理可离线进行。

| 附件 | 用途 |
| --- | --- |
| **UpxDrop.exe** | 软件主程序，日常使用只需下载这个文件。 |
| **UpxDrop.exe.sha256** | 主程序的 SHA-256 校验文件。 |
| **UpxDrop-1.2.2-source.zip** | 应用完整源码、构建脚本及对应 UPX 源码。 |

实际能缩小多少取决于程序本身；压缩校验通过后，发布前仍需要运行原程序确认功能正常。

更多操作说明见 [项目 README](https://github.com/Jay1023CN/upx-drop#readme)。
